# Dobry Sad

Idle-merge гра для благотворительности, рынок — Польша (интерфейс PL/EN).
Игрок помогает в основном просмотром рекламы (бесплатно), покупки опциональны.
Часть выручки с рекламы и покупок ежемесячно переводится партнёрскому фонду.

Издатель в игре указан как **+48 Gaming Studio** (студийный сплэш-экран
перед логотипом игры при запуске).

## Структура проекта

- `www/index.html` — вся игра (HTML/CSS/JS в одном файле): студийная и игровая
  заставка с логотипами, обучающая подсказка при первом запуске, звуковые
  эффекты (Web Audio API, без внешних аудиофайлов), сад-мердж с полосой
  созревания растений, склад сырья и мини-городок благотворительных зданий,
  магазин, рейтинг участников, голосование за фонд месяца. Открывается в
  любом браузере.
- `android/` — нативный Android-проект (`com.dobrysad.app`), сгенерированный
  [Capacitor](https://capacitorjs.com/).
- `.github/workflows/android-build.yml` — автосборка debug-APK на GitHub Actions
  при каждом push в `main` (или вручную через вкладку **Actions → Run workflow**).

### Механика созревания растений

После каждого объединения (или посадки) растение недолго «растёт» — над ним
видна тонкая полоса созревания, и в это время его нельзя снова объединить.
**Ручное объединение всегда бесплатно** — это просто небольшая пауза, не
платный барьер. Кто хочет обойтись без ожидания, может:

- посмотреть рекламу — все растущие растения на грядке сразу дозревают
  (бесплатно, кнопка «Podlej i przyspiesz» появляется, когда есть что полить);
- купить «⚙️ Auto-łączenie» — на 30 минут дозревшие растения объединяются
  сами, без нажатий (платно, Serduszka);
- купить «☀️ Lampa wzrostu ×2» — на 10 мин / 30 мин / 24 ч удваивает доход
  всей грядки (платно, три уровня цены на выбор).

### Склад сырья и городок благотворительности

Два сада дают не только Добро, а сырьё: **Gaj Drzewny** (дерево — семя →
росток → саженец → деревце → дерево → бревно) и **Kamieniołom** (камень →
кирка → кайло → кристалл → шестерня → гвозди). Когда растение на такой
грядке дорастает до максимума и готово, по нему видна иконка 📦 — тап
запускает короткую рекламу и сырьё переезжает на склад (вкладка 🗺️).

- **Вода** — основа для любой стройки — добывается только через рекламу
  (отдельная кнопка на складе), сад её не производит.
- **Переработка**: 5 🪨 камня → 1 ⚙️ металл; 3 ⚙️ металла → 1 🔩 гвоздь
  (каждый шаг — короткая реклама).
- Склад имеет предел вместимости — расширяется через рекламу.
- Из накопленных материалов строятся благотворительные здания (дом
  престарелых, детский дом, больница, хоспис, приют для животных) —
  каждое можно строить многократно (цена растёт), заселяет город жителями,
  и каждый житель добавляет немного Добра каждую секунду — материальный
  прогресс напрямую усиливает основную экономику игры.

## Как получить APK

1. Запушьте изменения в `main` (или откройте вкладку **Actions** этого репозитория
   и нажмите **Run workflow** для ручного запуска).
2. Дождитесь зелёной галочки (обычно 2–4 минуты).
3. Откройте завершённый workflow-run → внизу страницы раздел **Artifacts** →
   скачайте `dobrysad-debug-apk` (это zip с файлом `app-debug.apk` внутри).
4. Установите `app-debug.apk` на Android-телефон (в настройках может понадобиться
   разрешить установку из неизвестных источников — это нормально для debug-сборки).

Debug-APK подписан временным debug-ключом Android — его достаточно, чтобы
установить и протестировать игру на телефоне, но для публикации в Google Play
нужен release-билд с собственным ключом подписи (это отдельный шаг, не входит
в этот workflow, чтобы не хранить секретный ключ в публичном репозитории).

## Локальная разработка

```bash
npm install
npx cap sync android
npx cap open android   # откроет Android Studio, если она установлена
```
